### 🤖 [LocalAI-Gateway](https://github.com/AdriDob/LocalAI-Gateway)
> Unified AI provider OS — local-first routing by task type, cost tracking ($0 default), circuit-breaker failover, semantic cache.

- **Stack**: Python 3.11+, httpx, click | **Providers**: Ollama, OpenRouter, Groq, Together, DeepInfra, Cerebras, NVIDIA NIM
- **Tests**: 15 passing, zero network, zero keys | **CLI**: `localai-doctor` diagnostics

> Bug bounty automation pipeline — discover→recon→hypothesis→validation→evidence→report with economic prioritization.

- **Pipeline**: 13 stages with cooldown & EV-based ranking
- **Reasoning**: 5 vulnerability types with Hypothesis Challenger (IDOR, SSRF, XSS, SQLi, Auth Bypass)
- **Evidence**: Structured composer with integrity verification

### 🛰️ [ReconForge](https://github.com/AdriDob/ReconForge)

- **Tests**: 67 passing, zero network, zero keys | **License**: MIT

### 🔀 [AgentFlow](https://github.com/AdriDob/AgentFlow)

- **Tests**: 6 passing, offline | **License**: MIT

### 🌉 [legacy-bridge-perl](https://github.com/AdriDob/legacy-bridge-perl)

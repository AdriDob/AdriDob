## Flagship: OWNEX

**Autonomous Work Operating System** — a private intelligence platform that discovers
opportunities, reasons over targets, automates workflows, manages revenue intelligence,
and ships the evidence. One system, many loops.

| Area | What it does |
|------|--------------|
| **Opportunity Discovery** | Curated global sources scored by real barrier & expected value |
| **Security Pipeline** | Recon → hypothesis → validation → evidence → report, E2E automated |
| **Work Cycles** | Security, Forge, Pulse, Vault, Atlas, Direct Work — 28 scheduler jobs |
| **AI Runtime (OAR)** | Provider abstraction: local models, fallbacks, cost budget, routing |
| **Autonomy** | Agent orchestration, workflows, handoffs, approval gates, learning loops |
| **Evidence System** | Structured evidence, screenshots, integrity, export-ready reports |

**Stack:** Python 3.11 · FastAPI · SQLAlchemy · Vue 3 · TypeScript · Tailwind CSS 4 · Tauri · SQLite/PostgreSQL · pytest · Ruff · mypy
